
# Simple Calculator in C

## Aim
To develop a simple calculator using C.

## Operations
- Addition
- Subtraction
- Multiplication
- Division

## Algorithm
1. Start the program.
2. Display the menu.
3. Read the user's choice.
4. Read two numbers.
5. Perform the selected operation using switch.
6. Display the result.
7. Stop the program.

## Sample Input
Choice: 1
Numbers: 10 5

## Output
Result = 15

## Result
The simple calculator was implemented successfully using C.
